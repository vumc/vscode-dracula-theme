# Examples

Sample source files for manually verifying syntax highlighting across languages and theme variants (Dracula, Dracula Solid, Dracula Light/Alucard) in both the Zed and VSCode ports of this theme.

Every file tells the same story — a `Vampire`/`Dracula` themed demo — ported into that language's idiomatic syntax, so the same theme tokens (comments, doc comments, strings, numbers, keywords, types, functions, properties) are exercised consistently everywhere. To spot-check a color change, open a few of these files with the theme active and look for regressions.
